Flight Atlas — это [скилл для Claude](https://docs.claude.com/en/docs/agents-and-tools/agent-skills/overview). Вы пишете *«найди все мои перелёты в почте и сделай атлас»*. Claude ищет посадочные, маршрутные квитанции, напоминания о регистрации и чеки ОФД, вытаскивает каждый сегмент, спрашивает про пробелы и собирает одну самодостаточную веб-страницу:

- **Светящийся 3D-глобус** с реальными границами стран. Чем чаще маршрут, тем толще линия; страны, где вы были, подсвечены.
- **«Пролететь путь»**: самолётик по порядку пролетает все рейсы, камера следует за ним. Пауза, шаг вперёд и назад, шкала времени — тяните и смотрите, как растёт карта.
- **Статистика**: рейсы, километры, часы в небе, города, страны, авиакомпании.
- **Год за годом** (календарь по месяцам), **рекорды** (самый долгий, самый короткий, дальше всего от дома, самый плотный день), **силуэты стран**, **журнал рейсов** в стиле табло, маршруты и часы по авиакомпаниям.
- **Переключатель RU / EN** прямо на странице (названия городов, стран и авиакомпаний тоже переводятся), удобно с телефона, без сервера. Один HTML-файл, который можно выложить куда угодно.

Пример из реальной почты: 19 рейсов, 40 140 км (ровно один экватор), 65 часов в воздухе, 6 стран. Найдено среди лет почтового шума, включая старые домены авиакомпаний, чеки ОФД и ваучер туроператора.

## Установка

**claude.ai / Claude Desktop**
1. Скачайте [`flight-atlas.zip`](https://github.com/vladpomogaev/flight-atlas/raw/main/flight-atlas.zip).
2. Настройки → Возможности → Навыки → Загрузить навык.
3. Подключите Gmail (или другой почтовый коннектор).
4. Напишите: **«Найди все мои перелёты в почте и сделай атлас неба»**.

**Claude Code**
```bash
git clone https://github.com/vladpomogaev/flight-atlas
cp -r flight-atlas/skill/flight-atlas ~/.claude/skills/
```

## Собрать вручную

Без Claude? Напишите `flights.json` и запустите сборщик (Node 18+):

```bash
cd skill/flight-atlas/scripts && npm install
node build.mjs ../examples/vlad.ru.json my-atlas.html
```

```json
{
  "owner": {"ru": "Иван Петров", "en": "Ivan Petrov"},
  "lang": "ru",
  "home": "OMS",
  "homeGenitive": "Омска",
  "cityNames": {"OMS": "Омск", "SVO": "Москва"},
  "flights": [
    {"date": "2024-07-14", "flight": "DP6522", "airline": "Победа", "from": "OMS", "to": "SVO", "minutes": 215},
    {"date": "2026-11-17", "flight": "C6464", "airline": "Centrum Air", "from": "OMS", "to": "TAS", "status": "upcoming"}
  ]
}
```

`status`: `flown` (по умолчанию), `upcoming` или `refunded`. Если `minutes` не указаны, время в небе оценивается по расстоянию. В сборщик встроено 5 300+ аэропортов; аэропорты одного города группируются автоматически (SVO/VKO/DME → Москва). Для переключателя языков названия можно давать по языкам: `"cityNames": {"ru": {...}, "en": {...}}`, так же `countryNames`, `airlineNames` и `owner`. Русские названия популярных городов встроены.

## Приватность

Всё происходит внутри вашей сессии Claude, у страницы нет сервера. В файле данных только даты, номера рейсов, аэропорты и длительность — без кодов бронирования и номеров документов. Если публикуете атлас, лучше не включать будущие поездки: публичная страница с датами подсказывает чужим людям, когда вас нет дома.

## Как он находит рейсы

Один поиск никогда не находит всё. Скилл делает несколько проходов: ключевые слова на русском и английском, десятки доменов авиакомпаний и агрегаторов (включая переименованные, например `pobeda.aero` → `flypobeda.ru`), чеки ОФД с номерами билетов, «Промоакции» и корзина, и «поиск пробелов» вокруг поездок, которые видны по отелям, аэроэкспрессам или стрижке в другом городе. Подробности: [`search-playbook.md`](skill/flight-atlas/references/search-playbook.md).
